- **Project**: Browser enabler (Vite/TS) + processor service (Fastify 5/TS) connecting Nuvei PSP to commercetools Checkout via Connect.
- **Core Value**: Card-first reconciliation — no duplicate, missing, or misattributed transactions between browser Checkout, Nuvei, and commercetools Payments.
- **Constraints**: Idempotent state transitions; never log/expose secrets, PANs, or tokens; follow commercetools Connect patterns; verify against Nuvei sandbox before production claims.
- **CI**: GitHub Actions runs `commercetools connect validate`; use `npm ci` with committed lockfiles; add build + test gates before production.
- **Never deploy**: The user handles all deployments manually. Never trigger commercetools Connect deployments, redeployments, or deployment actions.
- **Do Not Use**: pnpm, Express/Koa/NestJS, Next.js/React for enabler, custom commercetools types, separate webhook service, browser-side status as final truth.
