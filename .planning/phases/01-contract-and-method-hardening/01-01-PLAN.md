<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Checkout/browser → Enabler constructor | Untrusted runtime options enter `NuveiEnabler` before any SDK or processor side effect. |
| Checkout/browser → Enabler builder dispatch | Untrusted component/drop-in type strings select supported payment UI. |
| Enabler → Processor `/payments` | Browser code sends method options to backend payment creation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01-CONFIG | Tampering | `validateEnablerOptions` | mitigate | Validate required options before builder creation and throw `CONFIG_INVALID` safe errors per D-01/D-03. |
| T-01-01-METHOD | Tampering | `NuveiEnabler.createComponentBuilder`, `createDropinBuilder` | mitigate | Registry-derived method checks reject unsupported builders with `METHOD_UNSUPPORTED` before SDK/processor side effects per D-04. |
| T-01-01-INFO | Information Disclosure | Public enabler errors and `onError` callbacks | mitigate | Public errors expose only code/message; diagnostic details stay redaction-safe and are not included in public messages per D-02. |
| T-01-01-SC | Tampering | npm installs | accept | No package installs are planned; Phase 1 uses existing dependencies and package-local npm tests only. |
</threat_model>
