<objective>
Rename the two mis-named processor routes, add GET /health, remove the dead GET /payments route,
rename the internal createPaymentIntent method to createPaymentSession, and fix two DTO
inconsistencies. All changes are surgical: no new dependencies, no behavior changes on existing
working routes.

Purpose: Remove Stripe-template naming artifacts from the processor API surface (D-01, D-04, D-08)
and give infra probes a lightweight unauthenticated health endpoint (D-10, D-11) that does not
require a Checkout session JWT. GET /status (D-12) and POST /webhooks/nuvei (D-09) are preserved
unchanged — their paths are platform contracts.

Output:
- nuvei-payment.route.ts: POST /session, POST /confirm/:id, GET / removed
- operation.route.ts: GET /health registered, no preHandler
- health.dto.ts: new DTO for health response shape
- abstract-payment.service.ts: abstract health() method added
- nuvei-payment.service.ts: createPaymentSession replaces createPaymentIntent; health() implemented
- payment-intents.dto.ts: PaymentIntentConfirmRequestSchema and its type alias removed
- transaction.dto.ts: centAmount Type.Integer() (was Type.Number())
- nuvei-payment.route.test.ts: route lookups updated to "/session", service mock renamed
- operation.route.test.ts: GET /health test cases added
</objective>

      public async health(): Promise<HealthResponseSchemaDTO> {
        const config = getConfig();
        const required = [
          { name: "CTP_PROJECT_KEY",        value: config.projectKey },
          { name: "CTP_CLIENT_ID",          value: config.clientId },
          { name: "CTP_CLIENT_SECRET",      value: config.clientSecret },
          { name: "CTP_AUTH_URL",           value: config.authUrl },
          { name: "CTP_API_URL",            value: config.apiUrl },
          { name: "CTP_SESSION_URL",        value: config.sessionUrl },
          { name: "CTP_CHECKOUT_URL",       value: config.checkoutUrl },
          { name: "CTP_JWKS_URL",           value: config.jwksUrl },
          { name: "CTP_JWT_ISSUER",         value: config.jwtIssuer },
          { name: "NUVEI_MERCHANT_ID",      value: config.nuveiMerchantId },
          { name: "NUVEI_MERCHANT_SITE_ID", value: config.nuveiMerchantSiteId },
          { name: "NUVEI_SECRET_KEY",       value: config.nuveiSecretKey },
          { name: "NUVEI_API_BASE_URL",     value: config.nuveiApiBaseUrl },
        ];
        const checks = required.map(({ name, value }) => ({
          name,
          status: (value && value.trim().length > 0) ? ("ok" as const) : ("failed" as const),
        }));
        return {
          status: checks.every((c) => c.status === "ok") ? "ok" : "degraded",
          checks,
        };
      }
