<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Nuvei public internet → local tunnel/proxy | External DMNs enter the local workstation over HTTPS tunnel. |
| DMN proxy → processor `/webhooks/nuvei` | Raw webhook body is forwarded to the real processor. |
| OAuth-like operation request → processor `/payment-intents/:id` | Local mock introspection grants operation scopes for evidence capture only. |
| Raw DMN/operation material → committed evidence | Sensitive webhook and operation data is sanitized before commit. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-02-04-01 | Information Disclosure | DMN raw bodies and checksums | mitigate | Raw DMNs stay under gitignored workspace; sanitizer fixed-redacts checksum fields and validator scans committed evidence. |
| T-02-04-02 | Tampering | Mismatch and duplicate fixtures | mitigate | Label synthetic-derived fixtures; preserve source linkage to real captured DMN without committing raw checksum/token values. |
| T-02-04-03 | Spoofing | Local OAuth introspection for operations | accept | Local-only evidence stage; operation auth is not claimed as real CT proof and cannot satisfy NUV-07/NUV-08. |
| T-02-04-04 | Elevation of Privilege | Tunnel startup | mitigate | Use installed `ngrok` binary or configured path; do not invoke `npx` or install tunnel packages. |
| T-02-04-05 | Repudiation | Canonical field conclusion | mitigate | Field matrix requires assessment and contradiction/blocker status per scenario. |
| T-02-SC | Tampering | npm/pip/cargo installs | accept | No new packages are installed or added by this plan. |
</threat_model>
