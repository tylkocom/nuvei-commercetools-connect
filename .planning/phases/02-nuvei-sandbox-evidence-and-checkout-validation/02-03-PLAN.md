<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser → raw workspace | Browser callback and operator notes become raw evidence files. |
| Nuvei-hosted fields → browser callbacks | Card and 3DS behavior crosses from Nuvei-controlled UI into connector callbacks. |
| Raw browser evidence → committed fixtures | Browser exports are sanitized and validated before commit. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-02-03-01 | Information Disclosure | Browser evidence export | mitigate | Export structured events only; no card input values, raw credentials, raw checksums, shopper PII, or full session tokens; validator scans output. |
| T-02-03-02 | Tampering | Browser callback treated as final truth | mitigate | Ingestion requires processor confirm/status and CT Payment snapshot alongside browser result. |
| T-02-03-03 | Repudiation | Web SDK feasibility | mitigate | Web SDK success or blocker must be recorded with exact attempt and reason per D-29. |
| T-02-03-04 | Spoofing | Local mock CT environment | accept | Local stage is explicitly labeled and cannot pass NUV-07/NUV-08. |
| T-02-SC | Tampering | npm/pip/cargo installs | accept | No new packages are installed or added by this plan. |
</threat_model>
