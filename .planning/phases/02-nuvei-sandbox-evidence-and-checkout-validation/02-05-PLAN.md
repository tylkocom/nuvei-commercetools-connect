<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Real commercetools Checkout UI → raw workspace | Hosted Checkout browser behavior and UI observations become raw evidence. |
| commercetools APIs/Merchant Center → raw workspace | Cart, Payment, and Order records may include shopper or operational data. |
| Nuvei dashboard/DMN/processor → raw workspace | PSP evidence may include transaction identifiers, checksums, tokens, and operational data. |
| Raw real Checkout evidence → committed fixtures | Sanitizer and final gate convert raw proof into committed machine-readable fixtures. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-02-05-01 | Information Disclosure | Real CT/Nuvei fixture output | mitigate | Sanitizer aliases IDs/tokens and redacts secrets/checksums/PAN-adjacent/PII before commit; final gate runs forbidden raw output scan. |
| T-02-05-02 | Tampering | NUV-07/NUV-08 proof status | mitigate | Gate requires real CT environment labels and all proof classes; mock/local evidence cannot pass. |
| T-02-05-03 | Repudiation | Phase completion claim | mitigate | Final index requires status/conclusion/fixtures/blockers for every scenario and refuses completion with unresolved required evidence. |
| T-02-05-04 | Information Disclosure | Optional screenshots/log excerpts | mitigate | JSON fixtures are canonical; screenshots/log excerpts are optional and sanitized/redacted when used for blockers. |
| T-02-SC | Tampering | npm/pip/cargo installs | accept | No new packages are installed or added by this plan. |
</threat_model>
